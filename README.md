# CIASecured company website

[Open the website](https://troykennels.github.io/ciasecured-website/)

A standalone public company website, separate from the existing client app.
Open index.html or serve the folder with any static HTTP server. No build step
or package installation is needed.

40 pages cover two product areas, 23 framework solutions, a searchable directory,
partnerships, pricing, company information, services and project enquiries.
Primary styles and interactions: redesign.css, editorial.css, interactions.js
enhancements.js and the homepage carousel.js. refinements.css applies the shared
type scale and page improvements. Older style
and script files remain in source but are not loaded by the current pages.

BUILD-BRIEF.md records the working prompts; DESIGN.md describes the design and
interactions. assets/APP-SCREENSHOTS.md records actual app capture provenance;
assets/PHOTO-CREDITS.md records photo sources and licence details.

Forms prepare reviewed email and WhatsApp drafts, with an optional clipboard
copy. Visitors choose how to send; there is no automatic submission or server-side
enquiry storage. Public
contacts supplied by the owner: famojuroadeyemi@gmail.com and WhatsApp
+44 7900 046798. The WhatsApp button is available on all pages. Search covers services and framework
pages, and framework enquiries retain the selected area.

Do not publish application databases, credentials or client records here.
Screenshots use an isolated sample workspace, not real client data.
Typography: locally hosted Source Serif 4 and Source Sans 3; see assets/FONT-CREDITS.md. No third-party scripts or external
fonts are loaded.

RESEARCH-AND-REVIEW.md records the international references and review outcomes.
