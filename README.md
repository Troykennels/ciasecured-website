# CIASecured website — UX/UI concept 01

A separate, responsive public website prototype for CIASecured, a security,
privacy and compliance implementation consultancy. The live application is
linked through Client portal and remains separate.

## Design direction

Deep ink/navy, teal, warm white and a restrained lime accent. Editorial
typography, crisp architectural graphics, varied section backgrounds and a
clear progression from services to delivery to an enquiry. No AI branding,
generated photography, invented customer logos, testimonials or statistics.

Mycroft (https://www.mycroft.io/) informed the navigation hierarchy and the
progression from services to approach. Layout, writing and graphics are
original to this prototype. No Mycroft assets or copy are reused.

## Review

Open `index.html` or serve this folder with any static HTTP server. There is
no build step or dependency installation. Navigation, service details,
framework tabs, FAQs, mobile menu and the enquiry preview are interactive.
The enquiry is a prototype: no message is sent or stored remotely. No contact
details, commercial claims or business certifications have been invented.

`DESIGN.md` records the page structure, palette and review notes. This folder
contains only public design source; it must never contain application access
details, customer information or copies of the application database.

Typography: Inter, distributed under the SIL Open Font License; see
`assets/INTER-LICENSE.txt`. The display face uses the visitor's system serif.
