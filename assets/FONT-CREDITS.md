# Website typography
Source Sans 3 for body text and interface controls; Source Serif 4 for headings.
Both families are by Adobe and distributed under the SIL Open Font License.
Latin variable WOFF2 files are hosted locally; no remote font request is made.
Sources: https://github.com/adobe-fonts/source-sans and https://github.com/adobe-fonts/source-serif
Licence files: sourcesans3-OFL.txt and sourceserif4-OFL.txt.
