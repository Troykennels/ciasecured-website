# CIASecured company website

Mycroft informs the navigation hierarchy, centred hero, product sections,
framework discovery, pricing enquiry and partnership journey. CIASecured uses
its own writing, branding, photos, app screens and implementation service scope.
No third-party customers, testimonials, logos or capability claims are reused.

Navy and mint establish the hero. Warm white, sage, cool blue and lavender
separate content sections. Technology photographs provide context; four actual
app views explain the workflow. Inter is locally hosted.

Product contains Audit & compliance and Third-party risk management. Solutions
contains all 23 available framework areas, a searchable directory and individual
pages. Coverage is distinguished: source catalogue, original guidance or limited
checkpoints. Planned ISO/IEC 27090 is not offered as available. Library inclusion
does not imply complete coverage, accreditation or certification.

Pricing follows the reference form structure: first name, last name, email,
company name and optional company information. Partnerships adds an optional
type. Engagement buttons preselect an interest. Forms validate, prepare a review
and open an encoded draft to the supplied public email. Visitors send it from
their own email app. Nothing is automatically sent or stored by this website.

The hero passes the visitor email in a URL fragment, then removes the fragment
after prefilling. It does not put the email in the server query string.

Accessibility includes keyboard dropdowns and screenshot tabs, native modal focus,
visible focus, reduced motion, labelled inputs and responsive navigation. WhatsApp
remains fixed on every page. Screenshots expand with a full-size image link.

All assets are locally hosted. The existing GitHub Pages project is retained.
The live app is separate. Screenshot and photo provenance are recorded in assets/.

The homepage now uses a full-width blue-lit technology photograph, without the
UK/international eyebrow or its dot. Technology photography also appears behind
product cards, supporting page banners, pricing/partnership sections and closing
invitations. Overlays keep text readable and distinct from the imagery.

## Photographic homepage and editorial typography
Hypersence (https://hypersence.com.ng/) was reviewed in a real browser as a
reference for a large, full-width photographic slideshow. CIASecured uses its
own three scenes: compliance review, implementation and review preparation.
The slideshow advances every ten seconds when the pointer is away. It pauses
on hover, keyboard focus, hidden tabs and when out of view. There are no visible
arrow or pause/play controls. Slide selectors, keyboard navigation and swipe
remain available. Reduced motion disables automatic rotation.

Headings use Source Serif 4; body text uses Source Sans 3. These replace Inter
throughout the public site. Fonts are locally hosted with OFL licence records.
Copy is written around practical client questions and the work people need to
do, with repeated slogan-like phrasing replaced by straightforward descriptions.
Illustrative stock photos do not identify the pictured people as staff or clients.

## Consistency and page review
refinements.css defines one relative type scale for headings, body text, labels,
links, captions and form controls. Source Serif 4 and Source Sans 3 remain the
site fonts. Website arrows are removed; original app screenshots remain authentic.

Search, framework filters and context-aware enquiry links help people find the
next step. Filters are restored from the URL on reload. Search runs locally.
Enquiry review offers email, WhatsApp and clipboard choices with no false sending
confirmation. Service outputs, related framework pages and practical questions
provide more useful page content. Website information and a working custom 404
complete the public routes. All requested changes retain the existing GitHub URL.


Decorative plus signs and divider rules are removed throughout the public website. Mobile navigation uses Menu and Close labels; spacing and coloured surfaces distinguish groups. Input boundaries and keyboard focus indicators remain visible.
