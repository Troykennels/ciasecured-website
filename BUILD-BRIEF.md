# CIASecured website build brief

## Editorial and visual direction
Build a mature UK implementation company website for an international audience.
Use British English, specific service descriptions, generous spacing and restrained typography.
Remove the three-word dotted strapline and repetitive slogan-like punctuation.
Use real licensed technology photography with ink and forest overlays, warm white
reading surfaces and lime accents. Maintain readable contrast, visible keyboard
focus, responsive layouts and working links. Do not invent client endorsements,
certifications, office addresses, statistics or contact information.

## Sequential working prompts
1. Homepage: establish the company, explain implementation services, introduce a
   real technology photograph as the main background and offer a clear route to
   services and project enquiries. Keep the first screen readable on small phones.
2. Services: create a service overview and individual pages for governance and
   risk, security implementation, privacy programmes and assurance preparation.
   Explain who the service helps, the work involved, outputs and scope boundaries.
3. Our approach: explain discovery, planning, delivery, review and handover, with
   client responsibilities and practical review points at each stage.
4. Standards: explain how ISO 27001, SOC 2 readiness, privacy and governance inform
   scoped implementation. Distinguish preparation from independent certification.
5. About: describe the UK base, international delivery and working principles,
   using only established company facts. No invented team biographies or offices.
6. Contact: provide a clear enquiry journey and access to the existing client
   portal. Retain honest preview status until a real delivery endpoint is supplied.
7. Verification and publication: check every page and local link, phone/tablet/
   desktop widths, navigation, keyboard access, forms and image loading. Publish
   to the existing GitHub Pages URL and verify the deployed revision.

## Scope
The public website is separate from the existing client application.
The enquiry preview must not imply that a message has been sent.
Photography must be stored locally with documented source and licence.
